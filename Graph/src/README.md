# Bài tập đồ thị

Thư mục gồm 12 lời giải C++ (Bài 01–12). Mỗi chương trình đọc đồ thị có trọng số bằng ma trận kề, dùng thuật toán Dijkstra để tìm và in đường đi ngắn nhất giữa hai đỉnh.
## Định dạng đầu vào : Grap.txt

```
n
đỉnh_đầu đỉnh_cuối
n hàng, mỗi hàng gồm n trọng số
```

Chỉ số đỉnh bắt đầu từ `0`; giá trị `0` trong ma trận được xem là không có cạnh. Dijkstra áp dụng cho đồ thị có trọng số không âm.
